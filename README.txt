DuoGrow Full Editable Website
==============================

FILES
index.html  - all editable website content
style.css   - complete design, mobile responsiveness, light + dark mode
script.js   - dark mode, saved theme, mobile menu and service cards

HOW TO RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

DARK MODE
The moon/sun button changes Light/Dark mode.
The selected mode is saved in localStorage, so it remains after refresh.

EDITING
Change business name, headings, services, phone number, email and CTA links in index.html.
Change colors and layout in style.css.
Change service cards in script.js.

The project thumbnails/dashboard are fully editable CSS UI elements rather than copied images.
